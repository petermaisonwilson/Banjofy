BANJOFY SONG ANALYSIS LABORATORY 006 — WINDOWS TEST
METER, BARS AND DOWNBEATS

PURPOSE
Prove the structural pass over a song that already passed Song Analysis
Laboratory 001.

ROOT-CAUSE CORRECTION
Earlier builds defined an application method called _root(). Tkinter already
uses _root() internally while creating Tk variables. This caused Tkinter to
call the Library-folder method before library_var had finished being created.

Laboratory 006 renames the application method to _library_root() and the
release gate forbids any application method named _root.

GitHub no longer treats a process that merely remains open as a startup pass.
The finished EXE must construct its real window, write a READY marker and exit
cleanly with code 0 under four settings conditions.

USE THE SAME LIBRARY
Do not delete or rename the successful Laboratory 001 Library files.

WINDOWS TEST
1. Run BanjofySongAnalysisLab006.exe.
2. Confirm the application window opens without an exception dialog.
3. Choose the TOP-LEVEL Banjofy Library root.
4. Select the song showing chord analysis: completed.
5. Click Detect Meter, Bars and Downbeats.
6. Wait for the completion message.

CHECK BY FILENAME ONLY
Confirm this NEW file exists:
Analysis\<song-id>\song_structure.json

OPEN AND INSPECT IN NOTEPAD
The following EXISTING filenames do not change.

A. Open:
Library\Songs\<existing-song-record-name>.json

Confirm its CONTENTS now include:
"structure_status": "completed"
"structure_summary"
"meter"
"meter_confidence"
"beats_per_bar"
"bar_count"
"bar_start_times"
"downbeat_times"

B. Open:
Analysis\<song-id>\song_analysis.json

Confirm its CONTENTS now include:
"meter"
"meter_confidence"
"beats_per_bar"
"beat_times"
"downbeat_times"
"bar_start_times"
"bar_count"
"beat_grid"
"bars"
"bar_aligned_chords"

TECHNICAL PASS
- Application opens without an exception.
- Structure analysis completes without error.
- New song_structure.json exists.
- Both existing JSON files contain the new fields.
- bar_count is greater than zero.
- downbeat_times and bar_aligned_chords are populated.

MUSICAL ACCURACY PASS
Listen and judge whether:
- estimated meter is credible;
- first downbeat is a real bar start;
- later bars remain aligned rather than drifting.

LIMITATION
This laboratory proves 2/4, 3/4 and 4/4.
It does not yet claim dependable 6/8 detection.
