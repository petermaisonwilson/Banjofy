BANJOFY FIREFOX ACQUISITION LABORATORY 001

PURPOSE
This is an isolated proof build on the firefox-acquisition-lab branch.
It does not replace or modify the stable Banjofy application.

WHAT IT PROVES
1. Firefox remains set to its normal Downloads folder.
2. The user chooses the Banjofy Library location.
3. The user enters the song title Banjofy is waiting for.
4. The existing Firefox downloader performs the download.
5. The laboratory ignores unrelated and incomplete files.
6. The matching completed media file is moved to:
   <selected Library>\Downloaded
7. A small .banjofy-import.json evidence file is written beside it.

WHAT IT DOES NOT YET DO
- It does not analyse chords or beats.
- It does not create a full Library song record.
- It does not change Firefox settings.
- It does not install or control the third-party extension.
- It does not contain yt-dlp or another downloader.
